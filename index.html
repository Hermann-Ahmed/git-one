Git & GitHub Practice

Simple HTML page for workflow exercises (commit, branch, PR).

Steps

  1. Create repository locally:
    git init
  2. Add files:
    git add indext.html
  3. Commit changes:
    git commit -m "init web practice"
  4. Push to GitHub:
    git branch -M main
    git remote add origin <URL>
    git push -u origin main
  5. Make edits, commit, push again for practice.
